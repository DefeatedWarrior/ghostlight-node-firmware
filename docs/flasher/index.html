Install Ghostlight Node firmware

Loading the list of boards…

Installing erases the node. Everything stored on it is wiped: network and Wi-Fi settings, port and universe settings, and scenes. Write down anything you want to keep before you start. To update a node and keep its settings, use the web UI instead (see below).
1

Pick your board

Firmware for the wrong board may not start, or may start with the wrong pins. If you are not sure, check the board list in the README.

2

Plug the node into this computer

Use a USB cable that carries data (some cables only charge). Use Chrome or Edge on a desktop or laptop: other browsers can't talk to USB devices.

If no port shows up in the next step: on an ESP32-S3 dev board, try its other USB socket. Hold the BOOT button while you plug in the cable. An ESP32 DevKitC may need the CP210x or CH340 USB driver for your computer.

3

Click Install

Choose the node's serial port in the box the browser opens, then confirm. Installing takes a minute or two. Don't unplug the node until it says it's done.

This browser can't install firmware. Open this page in Chrome or Edge on a desktop or laptop.

Installing only works when this page is opened over https.

After installing

The node restarts. With an Ethernet cable plugged in it gets an address from your network. Without one, it opens its own Wi-Fi network, called ESP-NODE- followed by four letters and digits. Join it with the password 12345678 and open http://192.168.4.1 to set the node up.

Updating a node that already runs this firmware

Download ghostlight-node-<board>-<version>-ota.bin for your board from the releases page, open the node's web UI, and upload the file under Firmware Update. This keeps the node's settings.

Uses ESP Web Tools. Source code: ghostlight-node-firmware.
