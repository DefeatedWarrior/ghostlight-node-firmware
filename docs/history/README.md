# Project history

These are the status reports, test plans and review notes from the original
ESP-NODE-2RDM v1.0-rc stage (December 2025). They are kept for reference only.

They describe the firmware before the network rework, the RDM bridge and the
board profiles, so much of what they list as missing or planned has since been
done. For the current state of the code, see [DEVELOPING.md](../DEVELOPING.md).
