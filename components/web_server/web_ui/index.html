    Tools

    Test patterns, the cable loopback test and DMX tester mode.

    DMX tester mode
    Turns the node into a DMX tester: send levels and test patterns with adjustable timing, analyse incoming DMX (refresh, slots, break / MAB, errors, frame jitter, flicker, signal loss), test cables and work with RDM fixtures. Art-Net and sACN stop while it is on. The setting survives a restart.

    Test pattern

    A test pattern replaces everything the port outputs (network data and scenes) until you stop it.

    Cable loopback test

    Connect a DMX cable from one port to another. The test sends five patterns and checks they arrive unchanged, then reports refresh rate, break / MAB and line errors. About 6 seconds.

    DMX tester

    Pick a port, choose its job, then send, analyse or talk RDM.

    Cable loopback test

    sendsPort 1
    receivesPort 2

    Plug a DMX cable (or the cable under test) from the sending port to the receiving port. Five patterns go out and must come back unchanged; the test also measures refresh rate, break / MAB and line errors. The ports go back to their jobs afterwards.
