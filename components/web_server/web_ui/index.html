Connection Mode

For a direct connection next to Ethernet or Wi-Fi. Without this, the access point only comes on when the node has no other connection, so you can always reach it.

Wi-Fi Networks

2.4 GHz networks only, up to 5. Networks in range are tried first, then in this order.
    Leave empty for an open network.

    Ethernet

    Lighting networks often have no DHCP server; use a static address there, for example 2.0.0.10 / 255.0.0.0 or 10.0.0.10 / 255.255.255.0.

    Access Point

    8–63 characters. The factory default (12345678) is not accepted.
    While the node is also on Wi-Fi, the access point uses that network's channel.
    The access point is at http://192.168.4.1/.

    Node Name

    Shown in Art-Net controllers and as the sACN source name. The http://….local/ address follows it after a restart.
    Lets an Art-Net console or tool set this node's IP address, mask, gateway or DHCP remotely. It changes the settings of the interface the console reached it on.

    DMX Tools

    Test pattern

    Replaces everything on the output (consoles, scenes) until you stop it. Use it to check cabling and fixtures without a console.

    Loopback self-test

    Connect a DMX cable from the output port to the input port, then run the test. It sends five patterns and checks every channel comes back unchanged. Both ports are borrowed for about 6 seconds and their settings are put back afterwards.
